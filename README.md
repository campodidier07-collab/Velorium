# ⌚ Velorium

Velorium es un sistema web de comercio electrónico para una relojería premium, desarrollado con PHP siguiendo el patrón MVC.

## Características

- Inicio moderno
- Catálogo de relojes
- Carrito de compras
- Autenticación de usuarios
- Panel administrativo
- Gestión de productos
- Gestión de pedidos
- Gestión de clientes

## Tecnologías

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/campodidier07-collab/Velorium.git
```

2. Importar `database.sql`.

3. Configurar la conexión a la base de datos.

4. Ejecutar el proyecto desde Laragon.
